## 2. S2：真实校线导入 → 位次趋势 → 对置版式（3–5 天，依赖数据）

**目标**：把 `alignment` 从恒定的 `unverified` 变成可计算的"证据一致性"。

- **数据**（关键阻塞）：你提供 ≥1 省的**考试院投档原表**（CSV / PDF / xlsx，列建议：年份 / 省 / 科类 / 院校 / 专业组 / 最低分 / 最低位次）。首选**广东**——设计评审核对的失败案例（广东 300000 误报 17 条"冲突"）就在这里。
  没有原表时，可先用 `gaokao-advisor` 的 21.7 万条真实录取记录做近似（在 `data_source` 上标注 `estimated_real`，与纯估算基线区分）。
- **工程**：
  1. `backend/scripts/import_school_lines.py` 已存在，扩展为接受原表并写入 `school_lines`（模型已有）。
  2. `verify.py` 新增"位次 3 年趋势"：对同一 `(省/科类/院校/专业组)` 取近 3 年最低位次，算 Δ 与方向。
  3. `alignment` 规则重做：`观点命题 P × 数据趋势 T → 支持 / 反驳 / 无证据`（替换当前恒 `unverified`）。
  4. 前端新增 `OppositionPanel` 组件：深色温度差——观点暖暗 `#241f14` / 数据冷暗 `#131a24`；`side="single"` 降级态（单侧无证据时整栏收起 + 顶部"数据未覆盖"条）。
  5. token 路径：扩展 `theme.js#themeVars`（`--xf-opinion-bg` / `--xf-data-bg`），**不碰 `--td-*`**。
- **验收**：广东某校某组，观点"避坑" + 数据"位次 3 年降 1.2 万" → 冲突有据，能指着数字说，不需要讲解。
