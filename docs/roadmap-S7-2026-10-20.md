## 1. 关于 S7-A 的一句实话

**通道做完了，但没有真的落进新的官方逐校数据——因为手上没有。**
`official` 这个标签的代价是「它会被当作权威口径呈献给用户」，所以：

- 仓库**不预置**任何逐校官方数据文件（只有目录 + README）；
- 官方原表要由运营投喂：拿到考试院原表 → 放进目录或管理端上传 → 一键落库；
- 抓取得来的 `estimated_real` 永远不会被自动升格为 `official`。

这不是把任务推后，而是这条数据**只能来自可点开的官方文件**；把来路不明的行标成官方，
比没有官方数据更糟。通道、校验、审计、幂等全部就绪，数据是运营动作而非工程缺口。

## 2. 已知限制（S8 需正视）

1. **官方逐校数据仍待投喂**：`official` 目前仍是 22 行「985/211 层次入门线」（6 省），
   加上落地区里运营后续放入的原表。真正的逐校扩面依赖外部文件到位。
2. **选科口径未覆盖「政治 / 地理」**：新高考 3+1+2 里要求政治或地理的专业，本模型统一归到
   「不限」或「历史」（引入会多出一个专业组维度，本轮未扩散）。受影响专业以思政类为主。
3. **种子仍在仓库历史里**：本轮起只提交 gzip（256 KB），但 S6 提交的 7.2 MB 明文 blob
   仍在 git 历史中，仓库体积不会因此缩小；新增长度已被压住。
4. **证据门槛是硬阈值**：10 条 / 5 所是拍定的经验值，尚未按省份数据量做分层校准；
   小省份可能长期落在 `unverified`，需要在 S8 观察真实分布后调。
5. **alignment 仍只核验「能否读到」**：S7-C 只是让这句话在样本不足时**不说**，
   没有把它推进到「观点 × 数据趋势」——那需要就业侧数据，不在本仓库能力范围内。
