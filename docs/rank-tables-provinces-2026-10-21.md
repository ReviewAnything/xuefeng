# 一分一段表：跨省落地现状与下一批方案（2026-10-21）

目标：31 省 × 2022–2026 的**官方一分一段表**（省考试院「成绩分段统计表」），
可点开溯源、逐行可校验，落到 `backend/data/rank_tables/{year}/{province}.json`。

## 1. 三种口径（数据分级的硬边界）

| 口径 | 定义 | 允许入库 | 备注 |
|---|---|---|---|
| `official` | 省考试院原表，且附件为**机读**（xls/xlsx/带文本层 PDF/HTML 表） | ✅ 默认落盘口径 | 必须有 `source_url` + 附件 sha256 |
| `reprint` | 教育门户转录官方原表（附门户 URL + 所引官方来源），机读 | ⚠️ 需显式标注，UI 必须可见 | 不得冒充 official；后续拿到原表再升格 |
| `pending` | 官方仅有图片/扫描件，无文本层 | ❌ 不落数据 | 只登记「已知存在 + 链接」，等 OCR 或另寻机读通道 |

**当前纪律**：`pending` 一律不 OCR、不臆造（广东 2023 扫描件、四川 2025 图片表、
河北 2025 图片 PDF 均按此处理）。

## 4. 下一批（按性价比排序）

优先「机读且体量大」的省，每省一次版式探查即可加一个适配器：

1. **浙江**（zjzs.net）——PDF 带文本层，**每页并排 3 组**（总分/人数/累计人数）。
   坑：网上流传的「二段线上考生成绩分数段表」明确标注**不含录取考生**，
   顶部高分者已被录取剔除，**不能当位次用**；必须取 6/25 发布的原表。
   解析要点：按表头 x 坐标切 3 个 block，块内自上而下读，块间顺序即分数降序。
2. **江苏**（jseea.cn）——历史/物理分表，通常 PDF。
3. **湖北**（hbea.edu.cn）、**湖南**（hneeb.cn）——3+1+2，物理/历史分表。
4. **福建**（eeafj.cn）、**安徽**（ahzsks.cn）、**陕西**（sneea.cn）、**重庆**（cqksy.cn）。
5. 北京/上海/天津/海南（3+3，综合表单表，形态接近山东，xls/PDF 皆有可能）。

每省落地检查单：
- [ ] 通知页 URL（可点开）+ 附件 URL + sha256
- [ ] 表头识别：分数列名含「分数/总分/分数段」；人数列含「本段/人数」；累计列含「累计」
- [ ] 顶部截断桶（「X 分及以上共 N 人」）记入 `top_note`，校验放宽为 `累计 ≥ 本段`
- [ ] 逐行 `累计 = 前项 + 本段` 全过，否则整份拒收
- [ ] 与官方通稿的 2–3 个锚点数字（一段线/特招线/最低分段人数）交叉核对
- [ ] `python scripts/import_rank_tables.py --year YYYY` 落库，抽 2 个分数点验证位次
