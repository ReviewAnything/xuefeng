# 官方逐校投档线落地区（S7-A）

这里放**各省教育考试院 / 省级招生考试机构发布的投档原表**，放进来的文件会被
管理端「一键落库」自动识别，落为 `school_lines` 的 `official` 行（可信度最高的一档）。

## 为什么是空目录

本仓库**不预置**任何逐校官方数据。原因很简单：我们手上没有可核实的省级考试院投档原表，
而把抓取数据（`estimated_real`）标成官方是自欺。`official` 这个标签的代价是——
**它会被当作权威口径呈献给用户**，所以数据只能来自可点开的官方文件，且必须带来源链接。

通道做完了，数据由运营投喂：拿到考试院原表 → 放进本目录 → 管理端点「一键落库」。

## 目录规则

- 只扫描 `*.json` 与 `*.csv`（`.md`、`.meta.json` 跳过）；子目录不递归。
- 每个文件可以自带 `meta`（JSON）或在管理端上传时填写默认值：
  `year` / `province` / `subject` / `batch` / `source_url` / `source_org`。
  行内字段优先级高于文件级默认值。

## 字段（JSON 用对象数组，CSV 用表头）

| 字段 | 必填 | 说明 |
|---|---|---|
| `university` / 院校 / 院校名称 | ✅ | 院校名，会与教育部 2868 所名单匹配，匹配不上**拒收** |
| `province` / 省份 | ✅ | 必须在 31 省名单内 |
| `subject` / 科类 | ✅ | 物理类 / 历史类 / 综合（理科→物理类，文科→历史类） |
| `year` / 年份 | ✅（或文件级默认） | 2000–2100 |
| `min_score` / 最低分 | 二选一 | 0–750 |
| `min_rank` / 最低位次 | 二选一 | 0–2,000,000 |
| `group_code` / 专业组 | ❌ | 缺省「官方投档」；唯一键的一部分，逐专业组请填真实组号 |
| `batch` / 批次 | ❌ | 缺省「普通类本科批」 |
| `source_url` / 来源 / 链接 | ✅ | **必须**是 http(s) 开头的官方文件链接，缺则拒收 |
| `source_org` / 来源机构 | ❌ | 如「广东省教育考试院」 |
| `note` / 备注 | ❌ | 附加说明 |

## 拒收规则（宁可少落，也不乱标）

省份无法识别 / 科类为空 / 年份异常 / 分数位次越界 / 校名匹配不上 /
**缺 `source_url`** ——任何一条命中即整行拒收，并在管理端返回拒收原因明细。

来源域名不在考试院机构特征列表内（如 `gov.cn`、`zsks`、`eea.`）时**不阻断**，
只在该行备注追加「来源域名 X 非考试院机构，需人工复核」，并在落库报告里给出
`provenance_warnings` 计数——把最终判断权留给运营，但把疑点留在数据里。

## 幂等

按 `(year, province, subject, university, group_code)` 唯一键 upsert：
重复落库只更新变化的行，不重复插入；变化会写进 `data_changes` 留痕。

## 示例（JSON，勿直接照抄数据）

```json
{
  "meta": {
    "year": 2024, "province": "广东", "subject": "物理类",
    "batch": "普通类本科批", "source_org": "广东省教育考试院",
    "source_url": "https://eea.gd.gov.cn/..."
  },
  "rows": [
    {"university": "中山大学", "group_code": "201", "min_score": 624, "min_rank": 8000},
    {"university": "华南理工大学", "group_code": "202", "min_score": 610, "min_rank": 13000}
  ]
}
```
